1. Server Configuration (AlmaLinux / WHM / VPS)

24/7 Daemon
Step 1.1: Install MediaMTX Binary

Download and extract MediaMTX to /opt/mediamtx and place binary in system path.

mkdir -p /opt/mediamtx && cd /opt/mediamtx wget https://github.com/bluenviron/mediamtx/releases/download/v1.9.0/mediamtx_v1.9.0_linux_amd64.tar.gz tar -zxvf mediamtx_v1.9.0_linux_amd64.tar.gz cp mediamtx /usr/local/bin/
Step 1.2: Create Systemd Service (Auto-Start on Boot)

Ensures the stream server restarts automatically if the server reboots or encounters an error.

cat << 'EOF' > /etc/systemd/system/mediamtx.service [Unit] Description=MediaMTX Live Streaming Server After=network.target [Service] Type=simple WorkingDirectory=/opt/mediamtx ExecStart=/usr/local/bin/mediamtx /opt/mediamtx/mediamtx.yml Restart=always RestartSec=5 User=root [Install] WantedBy=multi-user.target EOF systemctl daemon-reload systemctl enable --now mediamtx
Step 1.3: Open Firewall Ports

Opens RTMP ingest (1935), WebRTC player (8889), HLS (8888), and WebRTC UDP (8189).

# For Firewalld firewall-cmd --permanent --add-port=1935/tcp firewall-cmd --permanent --add-port=8889/tcp firewall-cmd --permanent --add-port=8888/tcp firewall-cmd --permanent --add-port=8189/udp firewall-cmd --reload # For CSF Firewall (if installed on WHM/cPanel) if [ -f /etc/csf/csf.conf ]; then sed -i 's/TCP_IN = "/TCP_IN = "1935,8888,8889,/' /etc/csf/csf.conf sed -i 's/UDP_IN = "/UDP_IN = "8189,/' /etc/csf/csf.conf csf -r fi

2. UNV / IP Camera Setup

Web Admin (192.168.8.x)
Menu Section Setting Parameter Recommended Value Why It Matters
Video & Audio → Video Video Compression H.264 Broadest compatibility with HTML5 WebRTC players.
Video & Audio → Video Resolution & Bitrate 1920x1080 @ 2048 Kbps (CBR) Stable streaming over 4G SIM bandwidth.
Video & Audio → Video I-Frame Interval (GOP) 50 (2x Framerate) Fast stream startup without buffering delay.
Video & Audio → Video U-Code / Smart Codec Off Proprietary compression must be off for standard RTMP.
Video & Audio → Audio Audio Input Off (or AAC if available) Avoids G.711 format sync dropouts.
Video & Audio → Media Stream Destination IP rtmp://earth.rechargingsolution.in:1935/live/camera1 Pushes video stream directly to your server.
Video & Audio → Media Stream Protocol & Persistent RTMP / Enable Keeps stream connected 24/7 automatically.

3. HTML5 Web Application Integration

viewer.php
Method A: Ultra-Low Latency WebRTC Player (Recommended <0.2s Delay)

Embed the MediaMTX WebRTC player directly in an iframe inside your web portal.

<div class="video-container" style="width: 100%; max-width: 900px; margin: 0 auto;"> <iframe src="http://earth.rechargingsolution.in:8889/live/camera1" style="width: 100%; height: 500px; border: 1px solid #1f2937; border-radius: 12px;" allow="autoplay; fullscreen"> </iframe> </div>
Method B: Native HTML5 HLS Player (Video.js / Hls.js)

For universal playback across all mobile browsers via HLS (.m3u8).

<script src="https://cdn.jsdelivr.net/npm/hls.js@latest"></script> <video id="videoPlayer" controls autoplay muted style="width: 100%; border-radius: 12px;"></video> <script> const video = document.getElementById('videoPlayer'); const hlsUrl = 'http://earth.rechargingsolution.in:8888/live/camera1/index.m3u8'; if (Hls.isSupported()) { const hls = new Hls(); hls.loadSource(hlsUrl); hls.attachMedia(video); } else if (video.canPlayType('application/vnd.apple.mpegurl')) { video.src = hlsUrl; } </script>
Security Best Practice: Wrap your viewer inside your application's requireAuth() PIN authentication so only authorized users can view the stream.
