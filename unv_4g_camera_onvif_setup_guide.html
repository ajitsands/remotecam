1. The Core 4G SIM Networking Reality

Crucial Architecture Knowledge

Why Remote ONVIF Fails On Standard SIM Cards

When your camera is powered by a standard 4G SIM card (Airtel, Jio, Vi, AT&T), mobile telecom towers place the SIM behind Carrier-Grade NAT (CGNAT). The SIM card does NOT get a public, routable IP, and all inbound traffic to port 80/554 is blocked by cellular firewalls.

Local Network Mode (Current)

Camera is connected to your local router with IP 192.168.100.113.

  • ONVIF Device Manager connects instantly on port 80.
  • RTSP stream plays directly via rtsp://192.168.100.113:554/.
  • Only accessible while your laptop is on the same local Wi-Fi / LAN.

Remote 4G SIM Mode (Target)

Camera sits at a remote site with only a 4G SIM card and 12V DC power.

  • Cannot connect inwards directly without a VPN or Static APN.
  • Camera pushes video OUTWARD to your cloud server via RTMP.
  • Accessible anywhere in the world through your Web Portal or EZStation.

2. Local ONVIF Connection (Verified Working)

Always ON by Default

Why There Is No "Enable ONVIF" Button on UNV Cameras

Unlike Hikvision cameras which have an ONVIF toggle and a separate user list, Uniview cameras have ONVIF active 24/7 by default. The primary admin user is automatically the ONVIF administrator using the exact same password you use for the camera web interface.

3. Remote Access Methods Over 4G SIM Card

Pick Your Preferred Workflow
Method A: Cloud RTMP & WebRTC (Recommended for Web Portal)
The camera pushes video outbound 24/7 over the 4G SIM to your MediaMTX server. You view it in real time from any browser with sub-0.2s latency.

Camera Web Interface Setting:

Navigate to Setup → Video & Audio → Media Stream (or Network → RTMP) inside http://192.168.100.113:
Field Name Value Action
RTMP Ingest Destination rtmp://earth.rechargingsolution.in:1935/live/camera1
Video Compression H.264 Required for HTML5 browser compatibility
Bitrate & Resolution 1920x1080 @ 2048 Kbps CBR Optimal for 4G cellular data stability
I-Frame Interval (GOP) 50 Enables instant video start when user connects
U-Code / Smart Codec OFF Proprietary codecs must be disabled for RTMP
Local Web Player: http://localhost:3031/ Production Web Player: https://remote.sandslab.com/webcam/viewer.php
Method B: Uniview EZStation Desktop Software (Official P2P VMS)
Uniview provides a dedicated desktop software (EZStation) that connects directly to the 4G camera over UNV’s secure P2P cloud relay without needing any static IP or open ports.

1. On Camera Web Admin:

  1. Go to Network → Platform Access.
  2. Select EZCloud.
  3. Check Enable & ensure status shows Online.
  4. Note down your Register Code or Cloud ID:
    210235C8PT32SC000040

2. On Your Remote PC:

  1. Download Uniview EZStation for Windows/Mac.
  2. Open EZStation → Log in with your EZCloud account.
  3. Click Device Management → Add Cloud Device.
  4. Enter the Register Code: 210235C8PT32SC000040.
  5. View live 4K/1080p stream with full PTZ controls!
Method C: Cloud RTSP Feed in ONVIF Device Manager / VMS
Your MediaMTX cloud server (earth.rechargingsolution.in) automatically converts the 4G camera's RTMP broadcast into an RTSP stream on port 8554. You can plug this directly into remote VMS software or VLC:
rtsp://earth.rechargingsolution.in:8554/live/camera1
Method D: Commercial IoT SIM Card with Public Static IP
If you specifically want ONVIF Device Manager on your PC to connect to the raw camera IP over the cellular network:
  • Obtain an IoT / M2M SIM card with a Static Public IP APN from your telecom carrier (Airtel, Jio, Vodafone).
  • Inside http://192.168.100.113, go to Network → Mobile Network and set the custom APN.
  • In ONVIF Device Manager, enter: http://<STATIC_PUBLIC_IP>:80/onvif/device_service.
